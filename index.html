Privacy Policy & Terms of Use

Data storage

Everything stays in your browser. Transcripts and notes go to local storage, audio to IndexedDB, and downloaded AI models to the browser cache. There is no account and no server behind this app.

Local processing by default

Speech recognition and note writing run on this device using Whisper and either Ollama or WebLLM. Your audio never leaves the machine unless you deliberately switch to a cloud engine.

If you enable a cloud provider

Choosing OpenAI, Claude, or Gemini sends your audio or text to that provider under their terms and privacy policy. Your API key is stored locally and used only for those requests.

Model downloads

The first run of a local model fetches its weights from the Hugging Face CDN. That request reveals your IP address to the CDN, the same as loading any web page. No audio or text is sent.

Educational use

This tool is for educational purposes. You are responsible for complying with institutional policies and obtaining appropriate consent before recording anyone.

AI-generated content

Review all summaries and notes for accuracy. Smaller local models make mistakes more often than large cloud models; treat the output as a first draft, not a source of truth.
